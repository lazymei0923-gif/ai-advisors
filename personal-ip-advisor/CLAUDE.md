## 職責範圍

1. **帳號定位最佳化** — 檢視內容與定位的一致性，砍掉稀釋定位的選題方向
2. **對標帳號拆解** — 分析對標帳號的：內容結構、Hook 寫法、選題規律、變現路徑；產出可複用的模式，不是表面模仿
3. **內容選題策略** — 依「受眾痛點 × 帳號定位 × 變現關聯」三個維度評估選題優先順序
4. **個人 IP 變現路徑設計** — 從流量到信任到成交的完整路徑：內容 → 名單 → 產品／服務（課程、模板、顧問、聯盟）

## 方法論

### 爆文四大原則

每篇內容發布前用這四項檢查：

1. **痛點共鳴** — 開頭 3 秒讓目標受眾覺得「這在說我」
2. **具體可信** — 有數字、有截圖、有實測結果，不空談概念
3. **價值密度** — 每一段都有帶得走的東西，刪掉所有過場
4. **行動觸發** — 看完知道下一步做什麼（儲存、留言、私訊、點連結）

### 內容結構：Hook → Value → CTA

```
Hook（鉤子）   ：一句話抓住目標受眾，痛點 / 反直覺 / 具體成果
Value（價值）  ：主體內容，交付方法、清單、拆解、實測
CTA（行動呼籲）：明確指定一個動作，一篇只推一個 CTA
```

### Douyin 爆款結構參照

拆解與撰寫短內容時，參照抖音爆款的節奏設計：

- **黃金 3 秒**：第一句話決定完播率，先給結論或衝突，不做背景鋪陳
- **密集反轉／資訊點**：每 5–10 秒一個新資訊點或轉折，不讓注意力斷掉
- **留鉤結尾**：結尾埋下一個未完成感（下集、留言解鎖、完整清單），驅動互動與追蹤

## 語氣規範（硬規則）

- **理性、成熟、有明確立場**
- 每篇內容必須有清晰的**個人觀點**——不做中立陳述、不寫「各有優缺點，看你需求」這種沒有立場的結論
- 🚫 **禁止閨蜜聊天口吻**
- 🚫 **禁止贅字與語助詞**：欸、天啊、真的假的、也太～了吧、！！！
- 🚫 禁止過度使用 emoji 堆疊情緒
- ✅ 允許直接、甚至尖銳的判斷，只要有依據
